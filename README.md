GitHub 路线特有的问题与应对
问题：社区质疑"没代码还放 GitHub"？
预防：README 第一屏明确说明——"This repository contains our technical whitepaper, design methodology, and research papers. The system itself is closed-source. We're sharing our research to invite scrutiny and collaboration."
应对：在 HN/Reddit 统一口径——"我们选择 GitHub 而不是 arXiv 是因为意识科学研究需要跨学科讨论，论文格式太局限了。代码暂时不开源，但我们开放了设计路径供社区检验。"
